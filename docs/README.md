## Adding a todo with a shortcut

Use `t DESCRIPTION` as a shorter form of `todo DESCRIPTION` in either
the GUI or CLI. For example, `t read book` adds the same task as
`todo read book`:

```text
Got it. Added to your never-ending pile:
[T][ ]read book
```

The description is required: `t` and `t   ` report
`A todo needs a description.` Commands are case-sensitive, and the
shortcut must be followed by a space and description. Other commands,
such as `task read book`, are not aliases. Saved tasks use the existing
todo format and remain available after restarting the application.
